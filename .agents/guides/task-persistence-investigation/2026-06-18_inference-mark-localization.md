# Where does the β inference-mark accumulate? — localizing the inference-specific persistent trace

**Head.** The consolidation arc (audit_103) showed β consolidates an
**inference-specific** component beyond encoding (`T_infspec·e` p=0.0068, β-only;
α = encoding-only). The standard trace's per-pair reorganization is known to
**over-accumulate in orbitofrontal cortex** (audit_83/92, R=1000, BH q≈0.01). This
asks the matching question for the inference-mark: **is there an anatomical
system where the β inference-specific persistent concordance OVER-ACCUMULATES,
in the same flavor as the OFC hotspot of the standard trace?** Pure reuse of the
audit_83 localization machinery — same rank concordance, same per-system demeaned
endpoint aggregation, same strength-preserving null — with the per-pair vector
swapped from the standard trace to the arc's encoding / inference vectors.

**Framing (LOCKED — [[feedback-localization-is-overexpression-not-container]]).**
A localization is an **OVEREXPRESSION / ACCUMULATION** hotspot on a trace
**distributed across the whole network** — never an exclusive container, never
"absent elsewhere". `M_obs` is per-patient **demeaned**, so every number is
concentration *above the distributed baseline*; the figure must show the
distributed field with the hotspot on top.

## Critical preamble (5 points, before code)

**(1) Claim.** The β inference-specific persistent concordance — `c^f_ij`
built from `f = D_taskTest − D_taskLearn` (inference-specific) vs
`p = D_restPost − D_preB` (persistent), with **encoding `e = D_taskLearn − D_preA`
residualized out of both** — over-accumulates in one (or few) a-priori anatomical
system(s) above a strength-preserving null, i.e. the inference-mark has an
anatomical hotspot like the standard trace's OFC.

**(2) Null.** Matched-strength 4-cycle ±δ surrogate, the **canonical**
`matched_strength_surrogate_lrg` ensemble (seed 20260511), per phase including
`task_learn` (generated by `audit_103 --null` at R=200; R=1000 task_learn not yet
cached). Per realization, recompute the *same* per-pair concordance on the
surrogate cophenetics; per-system per-patient-demeaned endpoint aggregation;
cohort-median upper-tail `p = (1+#{surr_med ≥ obs_med})/(R+1)`; BH across the 9
a-priori systems within the band. The null is **unchanged** from audit_83 — only
the observed per-pair statistic differs (no new null → no new-null validation
needed; matched-strength is the validated null).

**(3) Strongest alternatives.**
  (i) **Encoding leakage** — `f` and `e` share `D_taskLearn`; an apparent
      inference hotspot could be the encoding hotspot bleeding through.
  (ii) **Strength geometry** — the hotspot is just high/low-strength nodes.
  (iii) **Shaft pseudoreplication** — one electrode threading a structure inflates
      a system at contact level.
  (iv) **Difference-of-differences noise** — `f` is noisier than a single phase
      contrast, so a *weaker* localization could be noise, not absence.

**(4) Null's mechanical reach.** Matched-strength fixes per-node strength exactly
→ kills (ii) (and reports `strength_dev_median` as companion). Shaft-collapse
re-run (collapse each electrode shaft to one value) → addresses (iii). Encoding
leakage (i) is addressed two ways: (a) the **headline target residualizes `e` out
of both ranks** (partial concordance) so a surviving hotspot is encoding-orthogonal;
(b) the **encoding** target `concordance(e,p)` is localized separately and the maps
compared — if inference and encoding hotspots differ, leakage is not the whole
story. It does NOT separate `f` from `e` where they are perfectly collinear at the
pairs touching a system (stated limitation). (iv) widens the null → biases toward
**null**, so a surviving hotspot is conservative.

**(5) Falsification + limitations.** Falsified if β `inference_pe` does NOT exceed
its matched-strength null in any system (BH q≥0.05), OR if its hotspot coincides
exactly with the encoding hotspot AND vanishes once encoding is residualized
(pure leakage). **Limitations:** K≤5 implant ceiling per system (no DK region
sampled >5/10 — same coverage ceiling as the OFC verdict); single edge-cophenetic
probe (Grassmann subspace did not localize); the partial concordance is the
**residual form** of partial Spearman (tie-correction differs slightly from the
formula partial in audit_103 — both reported, must agree closely); no behavior, so
"inference-mark" is the offline residue of the inference-specific *reorganization*,
NOT inference *success* (that is the deferred behavioral TC1).

## Notation / targets

Canonical cophenetic `D_x` per phase (`eigh(L) → cophenetic_condensed_from_eigs`,
the construction the surrogate uses — NOT the LRG-pipeline ultrametric). Phase set
`{rest_pre_A, rest_pre_B, task_learn, task_test, rest_post}`. Differentials:

| symbol | definition | meaning |
|---|---|---|
| `g` | `D_taskTest − D_preA`   | inference-online / STANDARD task change |
| `e` | `D_taskLearn − D_preA`  | ENCODING |
| `f` | `D_taskTest − D_taskLearn` | INFERENCE-specific |
| `p` | `D_restPost − D_preB`   | PERSISTENT |

Per-pair concordance (rank-based, scale-invariant; `c_ij>0` = sign-consistent):

| target | per-pair statistic | localizes |
|---|---|---|
| `standard`      | `concordance(g, p)`            | the standard trace → reproduces OFC (CROSS-CHECK) |
| `encoding`      | `concordance(e, p)`            | where memorising accumulates |
| `inference_raw` | `concordance(f, p)`            | inference, NOT controlling encoding |
| `inference_pe`  | `concordance_partial(f, p\|e)` | inference CONTROLLING encoding = **the β inference-mark (HEADLINE)** |

`concordance_partial(a,b|c)` = elementwise product of the OLS residuals of
centered-rank(a) and centered-rank(b) on centered-rank(c); its normalized sum is
the residual-form first-order partial Spearman. Computed identically on observed
and surrogate.

## Cross-check gates (anti-hallucination)

1. `sum(concordance(g,p))/norm ≈ spearman(g,p)` and the standard-target cohort
   `M_obs[β, system, OFC]` reproduces `data/audit/localization_atlas/matched_strength_*_include.csv`
   (≈613264; loader-difference tolerance <1%). Proves the pipeline == canonical localizer.
2. `inference_raw` cohort `ρ(f,p)` and `inference_pe` residual-partial reproduce
   audit_103's `T_infspec` / `T_infspec_pe` (within tie-correction). Ties the
   localization to the validated arc numbers.

## Conditions

`region / system / supersystem / paracore` granularities; epi-include (primary) +
exclude; contact-level + shaft-collapse; R via `--R` (default 200). Multiplicity
family = the 9 systems within a band (matches the OFC verdict).
