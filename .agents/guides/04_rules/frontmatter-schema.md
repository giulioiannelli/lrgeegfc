# Frontmatter schema

**Every `.md` file in `.agents/` starts with a YAML block. Era and status
live here, not in the filename.**

## Required fields

```yaml
---
name: short-kebab-slug          # filename without date/extension
type: report | plan | guide | diary | post-mortem | rule
era: MSC | IMCOH_SQ | IMCOH_ABS | COHORT_N9 | CROSS_ERA
status: current | draft | superseded | dead
created: YYYY-MM-DD
updated: YYYY-MM-DD
pointers:                       # list of related files (relative paths)
  - path/to/related.md
---
```

## Era enum

Full definitions in `.agents/era-map.md`. Summary:
- **MSC** — pre-2026-04-15, magnitude-squared coherence
- **IMCOH_SQ** — 2026-04-10 to 2026-04-15, `|ImCoh|²` (buggy)
- **IMCOH_ABS** — 2026-04-15 onward, `<|ImCoh|>` (current)
- **COHORT_N9** — 2026-04-22 onward, 9-patient locked cohort on IMCOH_ABS
- **CROSS_ERA** — methodology / rule docs, not bound to any epoch

## Status enum

- **current** — load-bearing, cite freely
- **draft** — in progress, don't cite yet
- **superseded** — replaced by a newer file (reference in `pointers`)
- **dead** — investigation ended, kept for historical record

## Examples

**Current report**
```yaml
---
name: h1-h4-vi-results
type: report
era: COHORT_N9
status: current
created: 2026-04-24
updated: 2026-04-24
pointers:
  - .agents/reports/2026-04-24_multiscale-task-trace.md
  - .agents/reports/2026-04-15_imcoh-reset.md
---
```

**Superseded MSC-era report**
```yaml
---
name: coherence-fc-readme
type: report
era: MSC
status: superseded
created: 2025-11-25
updated: 2025-11-25
pointers:
  - .agents/guides/02_methods/imcoh-guide.md
  - .agents/era-map.md
---
```

**Dead investigation**
```yaml
---
name: post-mortem-scalar-session
type: post-mortem
era: COHORT_N9
status: current           # the post-mortem is current; the work it describes is dead
created: 2026-04-24
updated: 2026-04-24
pointers:
  - .agents/reports/archive/2026-04/
---
```

## Auto-scan

`.agents/MANIFEST.md` is generated by scanning frontmatter across all
`.md` files under `.agents/`. Rerun the scanner (to be added as
`scripts/00_prepare/scan_manifest.py`) instead of editing the manifest
by hand.
