# 2026-06-19

## Duration control SPLITS the verdict — memorizing→OFC robust, inference→cingulate downgraded

**Head.** Resumed the inference-mark thread after compact. The handoff listed a
length-equalized control as "optional/moot"; I checked the actual recording lengths
and it was **not moot** — `task_test` is **1.35–2.53× longer than `task_learn` in
all 10 patients** (median 1.57×), so the inference vector `f = D_taskTest −
D_taskLearn` could reflect `task_test` simply having ~1.6× more data — and this sits
directly under the marginal β cingulate result (q=0.050). Built the control in two
stages. **Verdict: it SPLITS the two sides.** Stage 1 (`audit_113`, observed) looked
reassuring — the cingulate inference direction held (8/8 sign). But that was an
under-powered "didn't drop" test, NOT a null test. **Stage 2 (`audit_113b`, the
matched-strength null regenerated on the truncated `task_test`) is decisive:
memorizing → OFC SURVIVES (standard q=0.025/0.050; encoding ⊥`task_test`), but
inference → cingulate does NOT (p=0.124/0.179, q≥0.42 — inside its null, not even the
top inference system).** So the marginal q=0.050 inference→cingulate was
**duration-assisted**; it's downgraded to a directional hint. The OFC memorizing
localization stands. *(I initially wrote this entry's head as "confound excluded"
after stage 1 — that was premature; stage 2 corrected it. Logged as the lesson.)*

## What the control does

Truncate `task_test` to `task_learn`'s sample count (3 window placements:
head/center/tail), recompute ONLY that phase's canonical cophenetic, rerun the exact
audit_110 localization with `D_task_test` swapped. Reuses the audit_110 / audit_83
machinery verbatim (no fork); recomputes the imcoh_abs FC from the truncated
timeseries via the same `compute_msc_welch(metric="imcoh")` + `_band_abs` path the
cache uses. Two built-in correctness checks, both pass:
- **Full-length recompute == cached cophenetic** (Spearman ρ=1.000000, max|Δ|≈1.5e-4
  = float32 rounding) on all 3 validation patients (Pat_02/06/15, spanning the ratio
  range) → my recompute pipeline IS the canonical cache.
- **Encoding target is bit-identical full-vs-matched** (`e = D_TL − D_preA` has no
  `task_test` dependence) → the swap logic is correct; any change would be a bug.

## Numbers (β, epi-include)

- Cingulate inference: of 8 cingulate-sampling patients, **8/8 keep the sign** of
  their per-patient demeaned value; cohort median **0.61× full** (+4.36e5→+2.67e5),
  per-patient full-vs-matched ρ=0.74; paired Wilcoxon matched-vs-full **p≈0.95
  (indistinguishable)**. The 5/8-positive cohort split is reproduced exactly.
- OFC standard survives (0.83–0.87× full, sign 5/5, ρ=0.90–1.0); OFC encoding
  identical by construction.
- The ~40% attenuation *looked* like a benign noise penalty in stage 1 — but stage 1
  is an *observed-robustness* check (did the point estimate drop?), NOT a null test.
  The decisive question is whether the attenuated observed still beats its
  matched-length null. → stage 2.

## Stage 2 — the decisive matched-length null (audit_113b)

Regenerate the matched-strength surrogate ON the truncated `task_test` (canonical
4-cycle ±δ, swap 20, seed 20260511; non-canonical cache so the canonical ensemble is
untouched), keep the cached full-length surrogates for the 4 unchanged phases,
recompute per-system matched-strength p + BH q (R=200, head). **It SPLITS:**

- **Memorizing → OFC SURVIVES.** standard OFC p=0.005, q=0.025 (incl) / 0.050 (excl);
  encoding ⊥`task_test` (full-length q=0.010 stands). The pipeline produces
  significance when warranted (OFC standard + occipital clear) → the inference
  failure is real, not a dead test.
- **Inference → cingulate does NOT survive.** cingulate inference p=0.124 (incl) /
  0.179 (excl), q=0.42/0.76 — inside its null, and only 3rd/2nd among inference
  systems (insula p=0.025, MTL p=0.040 above it). No system clears BH for inference.
  → the full-length q=0.050 was **duration-assisted**; downgraded to a directional
  hint. R won't rescue it (p=0.12 far from the floor); placement won't (needs
  ≈full-length observed). The OFC memorizing side stands.

## Lesson

Two. **(1) Check phase durations before dismissing a duration confound as "moot."**
The prior handoff's "argued moot by band/target-specificity" was wrong on the facts —
the durations differ a lot and one-directionally. **(2) An observed-robustness stage
is NOT a null test.** Stage 1's "8/8 sign, indistinguishable from full (p≈0.95)" felt
like a pass, and I wrote this entry's morning head as "confound excluded." But "the
point estimate didn't drop" (a low-power K=8 paired test) is a different claim from
"it still beats its matched-length null." Stage 2 showed inference→cingulate does NOT
beat the null — I had predicted it would reproduce q≈0.05, and I was wrong. Run the
null stage before calling a control passed.
