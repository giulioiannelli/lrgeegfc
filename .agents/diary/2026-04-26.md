# 2026-04-26

## Session — pivot to continuous-trace matrix

**Context:** MRL family null at hard thresholds; Cohesion-CBR shows
per-patient traces. Discrete-module formulation discards the per-pair
distance-shift magnitudes. Pivot to a continuous statement on `D` itself.

**Done:**
- Scope written and reviewed:
  `.agents/guides/task-persistence-investigation/2026-04-26_continuous-trace-matrix.md`.
  Defines `Δ_task = D_test − D_pre`, `Δ_rest = D_post − D_pre`,
  `σ = sgn(Δ_task)·sgn(Δ_rest) ∈ {−1, 0, +1}`, and per-(p, b)
  `ρ = Spearman(Δ_task, Δ_rest)`.
- Compute script:
  `scripts/01_compute/hypothesis_tests/continuous_trace_matrix.py`
  (uses `LRGResult.ultrametric_matrix` + `squareform`; reuses
  cached `imcoh_abs` LRG, no recompute).
- Per-cell figure (`fig_continuous_trace_per_cell.py`) — 4 panels:
  Δ_task, Δ_rest, σ heatmap, hex-bin scatter. Sanity check Pat_06 α
  ρ = +0.725, visually clear positive-diagonal cloud.
- Cohort figures (`fig_continuous_trace_cohort.py`) — cross-band
  dotplot + per-band 3-panel.

**Result (descriptive, shared D_pre baseline, n=10):**
59/60 cells positive. Median ρ +0.35 to +0.58 across bands; 9–10/10
patients positive in every band. Replicates the prior H2c 53/54-cell
finding at the now-restored cohort.

**Issues:** Both Δ vectors share `D_pre` → any noise in `D_pre` is
injected into both with the same sign. Spurious-correlation contribution
expected to be 0.3–0.5 of observed ρ. Three controls drafted:
- Run A — independent half-baselines (`D_pre_A ⊥ D_pre_B`).
- Run B — same-probe vs cross-probe pair split.
- Run C — within-session drift floor (already in H2e).

**Decisions:** PDF-only figures, rasterised heavy artists; no PNG
duplicates (saved feedback memory). Defer rendering all 60 per-cell
PDFs until controls clear.

**Files touched:** scope doc; 3 scripts; outputs under
`data/reports/imcoh_continuous_trace/`.

**Next:** execute Run A → B → C; consolidate.

## Session — three-control consolidation

**Context:** Quantify the shared-baseline artefact and pin the
band-specific claim.

**Done:**
- **Run A (`--mode split-baseline`).** Halves cache from `h2e_split_half`
  reused at `data/cache/imcoh_lrg_halves/` (24 LRGs/patient).
  Δ_task = D_test − D_pre_A, Δ_rest = D_post − D_pre_B.
  Drop ρ_shared − ρ_split = 0.25–0.52 across bands — matches the
  pre-registered prediction.
  Overlay figure: `figures/baseline_split_overlay.pdf`.
  Summary table: `run_A_baseline_split_summary.md`.
- **Run B (probe-bias).** Cross-probe vs same-probe split via
  `lrg_eegfc.utils.probe.build_probe_mask` on per-patient
  `channel_labels.csv` (with `PATIENT_CHANNEL_DROP` honoured).
- **Run C (drift floor).** Surfaced from
