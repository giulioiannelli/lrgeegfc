## Session — Sparsifier SETTLED once and for all: two schemes by readout

**Head.** Ran the full matched-strength sparsifier suite (trace gate + marker, per-scale,
tmfg/pmfg/disparity vs the mst family) and settled it: **trace = strength-ranked
`mst_union_top_fraction`@0.20; marker = TMFG (planar).** Planarity is disqualified for the trace
(it discards the strong edges the trace lives in — α clears 12/16 → **0/16** on TMFG), confirmed for
the marker (fused SOZ AUC 0.816 → **0.904**, β beats-null 8/10 → **10/10**). The dissociation is a
methods finding (magnitude- vs skeleton-carried structure), not filter-shopping.

### What was done
- **Library** (`src/lrg_eegfc/utils/fc/backbone.py`): added `pmfg_backbone` (exact planar, networkx
  planarity, ~9 s/graph), `disparity_backbone(W, alpha, ensure_connected)` (Serrano, MST-union to
  span), and `select_backbone(W, kind, frac, disparity_alpha)` dispatcher. Cited docstrings.
- **Pipelines** `06_epi_arc.py` (marker) + `13_matched_strength_mst020.py` (trace gate): env-driven
  `SA_BACKBONE` ∈ {mst020, tmfg, pmfg, disparity}, `SA_FRAC`, `SA_DISP_ALPHA`; per-backbone OUT dirs.
- **New script** `25_pmfg_observed_trace_readout.py`: PMFG≈TMFG observed-ρ_sym mechanism check.
- **Runs:** trace gate on tmfg / disparity@0.2 / mst@{0.10,0.05}; marker on mst@{0.05,0.10} /
  disparity@0.2 (tmfg marker already existed); PMFG-observed readout.

### The evidence
- **Trace clears/16 (matched-strength):** mst@0.20 → α 12, β 16, θ/low_γ 0 (CLEAN). TMFG → α **0**,
  β 3, θ 3, low_γ 7 (band-selectivity destroyed). disparity@0.2 → α 11, β 11 (keeps signal — the
  strength-based control) but low_γ 8 (leaks). mst@0.10/0.05 degrade (α/β weaker, low_γ leaks; β dies
  5/16 @0.05).
- **Mechanism (it's planarity, not sparsity):** at density 0.05, α ρ_sym = 0.24 (strength mst@0.05)
  vs **0.11 for PMFG-exact AND TMFG-greedy** → the planar family, not the greedy shortcut (PMFG≈TMFG).
- **Marker fused AUC monotone in sparsity** within mst (0.742@0.50 → 0.874@0.05); TMFG adds +0.03 /
  β 10-of-10 at equal density but **loses high_γ** (4/10). Kept as an honest caveat.

### Decision
Per the pre-registered §6 rule: global planar adoption **rejected** (trace fails), marker-only TMFG
**licensed**. User (2026-07-15) elected the two-backbone route for detection performance and framed
the split as a methods result. Docs: guide `.agents/guides/02_methods/sparsification-choice.md` §4a
(settled), verdict `.agents/reports/2026-07-15_sparsifier-suite-verdict.md`, memory
`sparsifier_two_scheme_settled_2026_07_15.md`.
