# 2026-05-07

## Session — KC trace module visualization locked at n=9 cohort

**Context:** Continuing from 2026-05-05. The KC scalar trace
(Section 5.2) is the load-bearing significance test, but it pools
topology and heights into one number. User asked for a visualization
that exposes the topology mechanism as identifiable subtree modules
that move from scattered (rPre) to coherent (tt+rPost). Earlier
sessions built `audit_47_kc_trace_network_view.py` as a 3 × 3 grid
(λ ∈ {0, 0.5, 1} × phase ∈ {rest_pre, task, rest_post}); each cell
pairs a dendrogram with the FC network. A trace module is a leaf
set whose tt-subtree matches a rPost subtree at Jaccard ≥ 0.65
and fragments in rPre at Jaccard < 0.5.

**Done:**
- **Two bug fixes** in `audit_47_kc_trace_network_view.py`:
  1. **Anchor false-positives** (Pat_13 α was the bug case). The
     j_pre Jaccard scan was size-restricted to `|L_tt|/1.5..|L_tt|*1.5`,
     so a 3-leaf L_tt fully contained in a 5-leaf rPre subtree
     (Jaccard 0.6) silently passed the gate. Fix — removed the size
     restriction on j_pre AND added explicit `FRAG_FACTOR = 2.0`:
     smallest rPre subtree containing L_tt must be ≥ 2·|L_tt|.
     Pat_13 α went from 3 spurious modules to 1 real one.
  2. **Merge-height bars invisible**. The original `ax.hlines`
     bounded to cluster x-range coincided with existing dendrogram
     brackets. Fix — full-width dashed `ax.axhline(alpha=0.65)`
     drawn for each module's `h_tt` and `h_post` at λ ∈ {0.5, 1}.
- **Cohort expanded to n=9** (Pat_07 + Pat_15 added; Pat_08 kept
  separately as the height-only counterexample).
- **Result snapshot.** 25/27 cells visible at λ = 0;
  +Pat_08 0/3 = 28/30 across the full n=10 cohort.
  - Pat_07 β [4, 4, 6, 22] — flagship many-module multiscale showcase.
  - Pat_07 α [4, 4, 6, 35] — second multiscale flagship.
  - Pat_10 α [25] — single 25-leaf module reorganizes ~22 % of brain.
  - Pat_05 low_γ [3, 9, 9, 19, 45] — densest cell.
  - Pat_06 β [5, 39] — load-bearing β band.
  - Pat_15 α and Pat_10 low_γ — empty cells in the visible cohort.
  - Pat_08 (0/3) — height-only-trace counterexample (5/5 scalar
    contributor at β but zero topology modules visible by
    construction).
