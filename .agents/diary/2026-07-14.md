## Session 14:49– — per-patient LOO influence as a clinical flag (idea + critical preamble, PRE-CODE)

**Head.** New exploration opened (session "per-patient-differences"). Idea from the
user: we have **no behavioral data**, but a single patient's large fluctuation vs the
cohort — especially in bands where **LOO makes a trace / encoding-specific /
inference-specific result *jump*** — might flag pathology or atypical behavior in that
patient. Logged **before any code** on purpose, so the framing is reviewable and we can
catch a wrong-footed start. This is a review checkpoint, not a result.

**Context.** Sprang from the brutal-honesty read on the idea as stated: *"big LOO jump →
pathology"* is, as phrased, **unfalsifiable in-dataset and confounded by electrode
coverage**. The instinct (per-patient deviation from cohort is where clinical signal
would live; [[feedback_fluctuations_are_signal]]) is right; the causal leap is the weak
link. We are recording the leap explicitly so a later review can see whether we started
from a sound footing.

**Critical preamble (5-point, per [[feedback_critical_null_preamble]]):**
1. **Claim.** A patient whose LOO removal moves a cohort trace / arc statistic by an
   outsized amount is clinically special (pathology / behavioral deviation).
2. **Null.** That patient's influence is no larger than expected from (a) 1/n arithmetic
   at n=10, (b) SNR / recording length, (c) electrode coverage — i.e. matched-strength
   surrogate influence + a coverage regression, not raw eyeballed jumps.
3. **Strongest alternative the null MUST control for → electrode coverage.** sEEG
   placement is *clinically chosen*, so coverage is already confounded with pathology; an
   "influential patient" flag can simply re-read where the electrodes went. Canonical
   trap: Pat_15 β anti-alignment = right-only implant (coverage), explicitly
   non-biological.
4. **Does the null control for it?** Only if we (i) compare observed per-patient
   influence to matched-strength surrogate influence AND (ii) regress influence on
   #contacts / hemisphere / SNR / length and test the **residual** against clinical
   ground truth. Raw LOO jumps alone do NOT — at n=10 every patient is ~1/n influential
   by construction.
5. **Falsification + limitations.** Falsified if influential patients are separable by
   coverage alone, or if their influence sits inside the surrogate band. Hard limitation:
   **no behavioral data ⇒ the pathology claim is unfalsifiable in-dataset**; the only
   anchor is partial clinical ground truth (SOZ extent, epileptogenic-contact count,
   hemisphere, possibly age / Engel outcome). Un-anchored, "weird patient ⇒ sick" is
   confidence-laundering ([[feedback_brutal_honesty_no_sycophancy]]).

**Prior that argues against (base rate).** [[interpatient_variability_resolution_2026_07_04]]
already resolved β interpatient spread to **LATERALITY** (electrode coverage / anatomy),
ρ.95 stable — last time we chased per-patient spread it was coverage, not a hidden trait.
That is the number to beat.

**Key tension flagged.** We currently use LOO **defensively** as a *fragility alarm*
(drop-one kills effect ⇒ claim weak; [[feedback_no_single_patient_p_driven]],
[[feedback_patient_counts_never_the_gate]]). This idea **reuses the same statistic
offensively** as a pathology *detector*. Nothing separates "patient breaks the claim
because the claim is thin" from "patient breaks the claim because the patient is deviant"
EXCEPT a null + a clinical anchor. If we forget this, we will relabel our own fragility
as a discovery.

**Decision / plan (agreed fast-first-cut = cheap kill test, before any surrogate
machinery):** pull the per-patient metadata we actually hold — SOZ extent, hemisphere,
#contacts, recording length — and check whether LOO-influential patients are separable
from coverage. If coverage explains them → idea dies cheap, no compute wasted. If not →
invest in jackknife / DFBETA influence vs matched-strength surrogate influence, then test
residual influence against SOZ / epileptogenicity.

**Review checkpoint (what would mean we started wrong):** (a) if we ever report a
"pathological patient" without first regressing out coverage → we fell into the Pat_15
trap; (b) if the influence metric is raw LOO Δ with no surrogate baseline → it's 1/n
arithmetic; (c) if we anchor to nothing clinical → the claim is untestable and must be
labeled speculative. Any of these = restart from this entry.

**Next.** Scope what clinical / coverage metadata exists per patient (read-only), report
the anchor set, then run the separability check.
