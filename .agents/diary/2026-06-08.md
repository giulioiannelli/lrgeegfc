# 2026-06-08

## Session — white-matter exclusion: does the task trace survive a gray-only montage?

**Context.** User asked for an entire report on how the trace results
change when white-matter (WM) contacts are removed from the timeseries.
Feasibility confirmed first: WM is cleanly labeled (each contact's
Desikan-Killiany cell carries tissue weights incl. `Wm` + a signed PTD),
and is a **large** fraction — 30–57 % of every montage (cohort ≈40 %),
so this is a structural cut, not a perturbation. User chose: WM =
atlas-dominant `Wm` (`region=="Wm"`); full mirror of the epi audits
(cophenetic + raw + Grassmann; subgraph + pair-class; all 6 bands; n=10;
matched-strength null on every submatrix).

**Key architectural facts.**
- "Remove WM from the timeseries" = FC submatrix exactly (ImCoh/corr/MSC
  are pairwise; gray-only FC == gray-only submatrix of cached FC). Only
  the node-coupled LRG step genuinely changes → recompute on submatrix.
- All three substrates ride **one** matched-strength eigendecomp ensemble
  per cell: `cophenetic_condensed_from_eigs` (coph),
  `adjacency_from_laplacian_eigs`→triu (raw), eigvecs→`topk_basis`
  (Grassmann). Adding raw cost zero extra surrogate generation.
- WM mask FC-index-aligned, length-checked (all 10 patients align; the
  `np.isin` no-op class of bug avoided).

**Built (mirror of audit_77/78, no forks).**
- `_wm_stratify.py` — WM mask + config vocab (full/exclude_wm/wm_only;
  gray_gray/cross/wm_wm) + surrogate cache namespacing
  (`matched_strength_surrogate_wm_{excluded,only}_lrg`, seed 20260608) +
  per-cell RNG. Reuses `cohort_verdict`/`sensitivity_flag`/`upper_tri`
  from `_epi_stratify` (import, not copy).
- `audit_83` cophenetic + raw ρ_split (6 configs × 6 bands × 2 substrates
  = 720 rows); `audit_84` Grassmann T_G(k) (re-emit full from audit_66,
  fresh exclude_wm/wm_only); `audit_83b` figures. Tidy cache at
  `data/audit/wm_stratified/`.

**Result — WM removal does NOT weaken the trace; it sharpens it.**
- Cophenetic: α **persists+strengthens** (+0.11→+0.18, p0.005→0.014);
  β **preserved/strengthened** (+0.22→+0.32, full-cohort p=0.053 marginal
  BUT obs↑, LO-Pat_15 p=0.037, gray_gray p=0.032, raw β p=0.024 — a
  node-count power crossing, NOT WM-carried); low-γ + θ **emerge**
  (p0.116→0.019, p0.688→0.005).
- Raw: the known-weak raw substrate **clears matched-strength at
  δ/α/β/low-γ once WM is removed** (β p0.053→0.024). Its full-graph
  weakness was largely WM strength-structure the null was matching.
- Grassmann: β/low-γ/high-γ subspace traces **unchanged** (β 40→40
  k-cells p<0.05; low-γ 41→40); only **δ weakens** (23→7) — and δ is the
  cross-probe epi-biology channel, not the task trace.
- `wm_only` carries weaker traces of its own (low-γ coph emerge; high-γ
  Grassmann) → gray-*dominant*, not gray-*exclusive*.

**Honest caveats (in report §4-5).** (1) `exclude_wm` cuts ~40 % of nodes
→ full-vs-exclude mixes biology with node-count change; matched-strength
is regenerated per submatrix so every significance is above
strength-matched chance, but the *delta* vs full is not N-controlled.
(2) Single WM definition (atlas-dominant; PTD<0 not run). (3) Grassmann
judged on Wilcoxon p, not the strict `separated` flag — the latter's
med_surr≈0 condition is cophenetic-calibrated and undercounts the
positive-offset chordal statistic (β-full clears Wilcoxon med p=0.024,
9/10, matching audit_66, yet 0 "separated").
