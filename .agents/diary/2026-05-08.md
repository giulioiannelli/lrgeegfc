## Reframe — regularities over BH-null (mid-session correction)

User pushed back on the "Direction A is null at n=9" framing:
*"we should really quit with that statistical null approach, we
have theories and ideas, we need to see regularities rather than
always start with statistical signals"*. Right pushback. The cohort
DOES have structured shape; the BH-FDR gate hid it.

Re-looked at per-band/per-λ Td_E with the IQR > 20% × |median|
floor (`feedback_iqr_vs_cohort_slope.md`). Three regularities pass:

| (band, λ) | direction | n_pat | median | %IQR |
|---|---|---|---|---|
| **δ / λ=1** | **RESET** | 7/9 | +0.53 | **75%** |
| **β / λ=1** | **RESET** | 6/9 | +0.15 | **43%** |
| **α / λ=0** | **TRACE** | 5/9 | −0.29 | **55%** |

The β-dissociation is the manuscript-worthy finding: at the band
where the cohort network shows the load-bearing TRACE (Result 2,
10/10), the epi-induced subtree at λ=1 shows the OPPOSITE — heights
shift in task and revert. Band-specific functional dissociation.
Direct testable consequence: subtracting epi nodes from the global
tree should sharpen the β trace.

δ-heights RESET is the largest single effect. Combined with the
n=10 revisit's δ cross-probe edge enrichment (1.55×), the layered
phenomenology is **strong + task-modulated + does not persist** —
three features of epileptic δ coupling that cohere only when read
across both edge-magnitude and cross-phase-hierarchy layers.

α-topology TRACE: the only band where the epi sub-network behaves
*like* the rest of the cortex.

## Followup — virtual resection on the LRG tree (audit_56)

User asked to run the testable followup from the β-dissociation:
*"subtract epi nodes and recompute Section-5 β trace; does it
sharpen, weaken, or stay the same?"*

`scripts/01_compute/audit/audit_56_trace_minus_epi.py` does the
induced-subtree-on-V\E_p version. CSVs at
`data/audit/trace_minus_epi/`. Verdict at
`.agents/reports/2026-05-08_trace-minus-epi-resection.md`.

**Three regularities:**

1. **β trace is non-epi-carried.** Per-patient Td values barely
   change with resection at all three λ values (β/λ=0:
   −2.45 → −2.26; β/λ=0.5: −0.58 → −0.46; β/λ=1: −1.42 → −1.44).
   The Result 2 cohort signal lives in the non-epi part of the
   tree. The audit_54 epi-only β/λ=1 RESET is a separate
   sub-network signal that coexists without interfering.
2. **α/λ=0 trace strengthens** with resection (cohort median
   −0.81 → −1.29; IQR fraction 19% → 40%). The "subtract epi
   sharpens trace" intuition holds at α-topology specifically.
   Worth a sentence in the manuscript Section 5 discussion.
3. **δ/λ=0 direction flips** (full +2.01 RESET → resect −0.09
   flat). The global δ-topology RESET was an interface effect;
   the non-epi-only tree has no clean direction at δ-topology.
   Combined with audit_54's epi-only flat at δ/λ=0 (median −0.13)
   the picture is: δ-topology has no clean trace or reset signal
   in either sub-network alone, but their interaction looks like
   global RESET.
