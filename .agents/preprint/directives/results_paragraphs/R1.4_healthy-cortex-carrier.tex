\paragraph{The \(\beta\) trace is carried by healthy cortical coupling.}
We have placed the \(\beta\) trace in \gls{ofc} and shown that it lives in the network's multiscale geometry rather than its raw edges; both readings have treated it as a neural signal. But these recordings come from epilepsy patients, implanted because of pathology, which raises a confound specific to clinical data: the persistence we attribute to reasoning could instead ride the epileptogenic network that motivated the implant. Telling the two apart means asking not merely whether the trace is present but which tissue carries it. We labeled every node pair by the tissue it links --- cortical gray matter, white matter, or the clinically defined \gls{soz} --- and asked which classes carry the \(\beta\) trace more strongly than a random set of pairs of the same size drawn from the whole network (a pair-class control, \(R = 1000\)). The answer is healthy cortex: the \(\beta\) trace concentrates in coupling between gray-matter contacts, which carry it well above the random-pair baseline (\(p < 0.001\)) and clear the strength-matched surrogate (\(p = 0.042\)). The other tissue classes carry less of the \(\beta\) trace: white-matter coupling sits below the random-pair baseline, and pairs internal to the \gls{soz} carry no more of it than a random set of the same size (\(p = 0.93\)); neither class clears the strength-matched null. Removing the seizure-onset contacts from the network altogether leaves both the cohort \(\beta\) and \(\alpha\) traces intact; any apparent change in magnitude on exclusion is accounted for by node count alone, as a random-decimation control reproduces it. The \(\beta\) trace is therefore a property of coupling among healthy cortex --- neither a pathology artifact nor an everywhere-and-nowhere effect.
