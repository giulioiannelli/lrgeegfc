# R-7 · The flagship (N2) result — the *inference* persists, β only

## Slide placeholder (copy into Canva)

**Main point.** The climax. The **inference-specific** component — the transitive
order the brain *reasoned out*, with encoding controlled out — **itself persists into
post-task rest**, in **β and no other band**. Post-task rest holds not just the pairs
it saw, but the **order it inferred**: an **offline abstraction of a learned order**.

**Concepts to land.**
- **β inference-specific persistence clears the null:** **+0.091 vs null +0.005,
  p = 0.0098** (LO-Pat_15 0.020, 6/10). **Multiscale-robust** — it also clears at a
  coarser scale (τ ≈ 2.6, p = 0.0049); **not** a single peak. **Duration-immune** —
  no relationship to phase length (ρ = +0.10, p = 0.78), so it is *not* a "more time =
  more drift" artifact. **Every other band is null** (next best p ≈ 0.25).
- **The anatomy is set by learning.** **Encoding → OFC in both phases**
  (q = 0.010 excl / 0.040 incl; PFC depleted) — the map is laid down in OFC, and the
  inference rides the same address. **Cingulate multiplexes:** **low-γ → cingulate
  memory** is the solid cingulate result (q = 0.035, 8/8); **inference → cingulate is
  a directional *lead* only** (it fails length-matching — a hint, not a localization).
- **What it means (interpretation, stated as such):** a relational structure,
  assembled during reasoning, is **replayed-as-held** offline in β — the brain
  consolidates the *inferred* order, not merely the *observed* pairs.

## Keep honest (content constraints, not styling)

- **β inference is a CONVERGENCE phenomenon — not *exclusively* multiscale.** Under
  matched-strength, the inference-specific β signal is **also** seen by raw edges
  (p = 0.010), eigencentrality (0.002), closeness (0.024). So say **"fine-grained, not
  coarse-spectral"** — **not** "specifically multiscale." (Walks back the earlier
  N2.7 "specifically multiscale" wording, 2026-07-09.)
- **Grassmann does NOT second-witness the inference-specific trace** (audit_165:
  T_G^infspec null in every band). The two-probe agreement (R-4) is for the
  *whole-task* β trace, **not** for inference-specific. Don't claim Grassmann
  corroborates N2.
- **The "conditional inference = drift" reading is WITHDRAWN (2026-07-10).** A windowed
  drift null is **invalid** for the conditional T_infspec (it returns a spurious
  positive on a no-signal pre-task arc). N2 stands on the **matched-strength** β-only
  p = 0.0098 **+ duration-immunity**; the β whole-task trace is separately drift-clean
  via the fair full-duration C2 (0.0137). Never present N2 as drift-confounded.
- **Inference → cingulate is a directional LEAD only** (fails length-matching) — do
  **not** upgrade it to a co-localization. The solid cingulate result is
  **low-γ → cingulate memory** (q = 0.035, 8/8).
- **Multiscale ROBUSTNESS, not a peak** (structure-file flag 2) — the τ-sweep has no
  interior maximum. Keep relational-chaining as motivation, not a located scale.
- **No behavioural data** — "abstraction of a learned order" is an interpretation from
  design + anatomy + literature, never a brain–behaviour correlation.
