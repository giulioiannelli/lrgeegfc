# Talk slides — per-slide expansions

## Head

One markdown file per slide of the 20-minute talk, expanding each row of
the [structure file](../../reports/2026-07-07_talk-structure-20min.md) into
a build-ready spec: **what goes on the Canva slide**, **what you say**, the
figure to drop in, the transition, and the guardrails. The structure file
stays the single source of truth for the arc and the numbers; these files
are the shooting script. Slides are built in **Canva** (no HTML deck).

## Per-slide file template

Each file is a **copy-paste content placeholder** for Canva — concepts and
figures, **not** aesthetics. It deliberately does NOT prescribe titles, layout,
colours, fonts, positions, build order, or scripted wording — those are the
presenter's degrees of freedom, adjusted while building. Sections:

1. **Slide placeholder (copy into Canva)** — the block you paste:
   - **Main point** — one line, the slide's job.
   - **Concepts to land** — the substance, plain language.
   - **Figures / visuals** — what to show (conceptually) + the **file path(s)**.
   - **References** — citations with DOIs (if any).
2. **Keep honest** — content/integrity constraints only (e.g. ρ_sym numbers, the
   no-behavior caveat, no-overclaim notes). Not styling.
3. **Open decision** — genuine content choices still to make (if any).
