# I-2 · The task, and the rare data

## Slide placeholder (copy into Canva)

**Main point.** One compressed slide for everything we can honestly say: the task
is transitive inference — from shown pairs the brain builds a **relational map**
you read new facts off — and we watch it **directly**, with intracranial
electrodes, across four phases that separate encoding from inference and catch
what persists.

**Concepts to land.**
- The task = **transitive inference** (the thing you just did): from neighbour
  pairs the brain builds a **relational structure / cognitive map**, not a
  memorised list — you can read off comparisons you were never shown.
- The data is **rare**: **sEEG (intracranial) in epilepsy patients** — the
  millimetre / millisecond window you cannot get non-invasively. **n = 10.**
- **Four phases: rest_pre → task_learn → task_test → rest_post.** This bracket
  separates **encoding** (what was shown, `task_learn`) from **inference** (what
  was reasoned out, `task_test`), and — crucially — catches what **persists**
  into post-task rest.
- Two seeded bets (setup, *not* claims — they pay off later): a relational map
  plausibly consolidates **offline, in post-task rest**, and plausibly in
  **orbitofrontal cortex**.

**Figures / visuals.**
- 4-phase timeline (rest_pre → task_learn → task_test → rest_post) — build in

## Keep honest (content constraints, not styling)

- **No behavioral data — say it once, plainly.** TI performance is unavailable
  and won't be obtained. "Abstraction / consolidation" is read from task
  structure + anatomy + literature, **never** from a brain–behavior correlation.
  Don't imply performance data exists.
- The **offline-rest** and **OFC** expectations here are *bets / setup*, not
  results — don't present them as findings (OFC pays off at R-3, offline at R-5).
- We know the **basics** of the task — don't oversell task detail.
