# Slide 18 — Inference persists (β only), and localizes

1. TITLE
Inference persists — β only — encoding → OFC, inference → cingulate

2. MAIN CONCEPT
- The climax: the inference-specific component — the order the brain reasoned out, encoding controlled out — itself persists into post-task rest. In β, and no other band: +0.091 vs a matched-strength null of +0.005, p = 0.0098; duration-immune; every other band null. Rest holds the order it inferred, not just the pairs it saw — an offline abstraction of a learned relational map (interpretation, not a behavioural claim).
- And it localizes, as a dissociation: encoding (the seen pairs) → OFC; inference (the reasoned order) → cingulate.
- On the inference cell, DETECTION is tied — raw = cophenetic, both p = 0.0098 (the cophenetic distance is built from the same edges, so it cannot detect more). The multiscale value-add here is LOCALIZATION: cophenetic pools many weak edges into a coherent cingulate hotspot (matched-strength BH q = 0.03/0.04, LOO-robust) that the raw edges cannot — raw is placeless.
- Honest caveat: the duration control on inference → cingulate is open — a length-matched null demotes it to p ≈ 0.124, but that windowed null is likely invalid for a conditional quantity (same reason drift is), so it is contested, not a clean negative.
- Companion band result: whole-brain low-γ is ZERO, but that zero MASKS a focal low-γ ENCODING trace in the cingulate (8/8, q = 0.035) — a memorising copy of the learning phase, distinct from the β inference.

4. SPEECH
This is the climax, in two parts. First: we take the inference-specific component — the order it reasoned out, with encoding controlled away — and ask if it survives into rest. It does, in β and no other band: plus 0.091 against a matched-strength null of essentially zero, p about 0.01; it doesn't scale with phase length, so it isn't time-on-task, and every other band sits on the null. So post-task rest holds not just the pairs the brain saw, but the order it inferred — an offline abstraction of a learned relational map.
Second: where. The two components dissociate — the seen pairs localize to OFC, the inferred order to the cingulate. One honest subtlety: on the inference component, detection is tied — our cophenetic measure is built from the same edges, so raw and cophenetic agree on the p-value. What differs is where they put it: the hierarchy pools many weak edges into a coherent cingulate hotspot that clears the strength-matched null, while the raw edges point nowhere that survives. So here the multiscale value-add isn't detection — it's localization. And I'll be honest: the duration control on that cingulate localization is still open, so I show it as a strong lead, not a closed result.

Careful: β inference is a convergence effect — raw edges and centrality see it too, so say "fine-grained", not "exclusively multiscale"; Grassmann does NOT second-witness it; it stands on matched-strength + duration-immunity (the "conditional = drift" reading is withdrawn). On the cingulate the exact claim is "localization, NOT detection" (raw ties by construction) — never say coph "detects better". Duration control on inference→cingulate is genuinely open (length-null p ≈ 0.124, likely invalid for a conditional). Don't conflate β-inference→cingulate with the separate low-γ-encoding→cingulate result. No behavioural data.
