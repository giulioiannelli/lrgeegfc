# Slide 19 — The band taxonomy: β is the flagship

1. TITLE
The band taxonomy — β is the flagship

2. MAIN CONCEPT
- One glance across all bands, one argument — don't go band by band:
  - β: holds AND localizes (OFC) — the only band that does both. Flagship.
  - α: holds cohort-wide (gate p = 0.024) but has no anatomical home.
  - low-γ: whole-brain shows ZERO — but that zero MASKS a focal cingulate trace that is specifically ENCODING (it persists the learning phase), 8/8 patients (q = 0.035).
  - δ: clinical (the epilepsy marker — next slide).
  - θ: silent — and that silence is the evidence: a global artefact would light every band.
- Never rank bands by the ×null ratio: γ_low has the biggest single-patient number yet fails the cohort gate. Only β clears the full bar.

3. ON-SLIDE TEXT
β: holds + localizes (OFC) — flagship
α: holds, no anatomical home
low-γ: whole-brain ZERO → masks a focal cingulate ENCODING trace (8/8)
δ: clinical   ·   θ: silent
θ-silence ⇒ band-selectivity is not an artefact

4. SPEECH
Zooming out to every band, the point isn't a catalogue — it's one argument. β is the only band that both holds and localizes; that's the flagship. The others tell a graded story: α holds across the cohort but doesn't localize; low-γ looks empty whole-brain but hides a focal cingulate memory trace; δ is really a clinical signal, which is the next slide. And θ is silent — that silence matters, because if all of this were a recording artefact or a global shift, every band would light up. Band-selectivity is itself the control.
